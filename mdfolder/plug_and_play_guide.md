# 🔌 FractalSwarm: Plug-and-Play Integration Guide

This guide explains how to decouple and integrate **FractalSwarm (AetherSRE V2)**'s modular components—including the Zig/WASM cache, Context Compressor, Enkrypt AI Safety Guard, and Mastra Steps—into any existing external production workflow, application, or CI/CD pipeline.

---

## 🛠️ 1. Integrating the Zig/WASM POPCNT Matcher
If you want to add sub-millisecond local duplicate filtering to your existing alert ingestion pipelines before sending alerts to an LLM or cloud database:

### How to use:
Directly import the quantization and matching functions or hit the isolated HTTP endpoint.

#### REST API Integration:
```bash
# Query the local WASM cache from any scripting language
curl -X POST http://localhost:3002/api/memory-vault/query \
  -H "Content-Type: application/json" \
  -d '{
    "floatVector": [...384d float array...],
    "topK": 1,
    "queryText": "No space left on device"
  }'
```

#### Code Integration:
Copy the matching functions from [routes.ts](file:///d:/HiDevs/GoogleAgents/server/features/memory-vault/routes.ts):
```typescript
import { quantizeFloatVector, searchLocalWasm } from './memory-vault/routes';

// 1. Quantize your float embeddings in-process
const packedQuery = quantizeFloatVector(embeddings);

// 2. Scan locally via Zig WebAssembly
const match = searchLocalWasm(packedQuery, 1);
if (match.results[0]?.bit_density >= 87.5) {
  // Use local playbook instantly (<0.3ms)!
}
```

## 🛡️ 2. Standalone Command Safety Audits (Enkrypt AI)
You can intercept and validate commands generated by *any* external AI agent or pipeline before executing them in a shell.

### REST API Integration:
```bash
curl -X POST http://localhost:3002/api/safety-guard/audit \
  -H "Content-Type: application/json" \
  -d '{
    "command": "rm -rf /etc/passwd"
  }'
```

### Code Integration:
Copy the audit cell from [routes.ts](file:///d:/HiDevs/GoogleAgents/server/features/safety-guard/routes.ts):
```typescript
import { auditCommand } from './safety-guard/routes';

const auditResult = await auditCommand("systemctl restart nginx");
if (!auditResult.isSafe) {
  throw new Error(`Execution Blocked: ${auditResult.reason}`);
}
```

import { compressAgentContext } from './incident-agent/compressor';

const rawLogs = "ERROR 2026-07-01 02:40:36: Out of memory... (100 lines of trace)";

## 🤖 4. Reusing Mastra Workflow Steps
Our workflow steps are defined as modular composables. You can import them directly into any custom Mastra workflow you are building in other projects:

```typescript
import { createWorkflow } from '@mastra/core/workflows';
import { 
  triageStep, 
  safetyAuditStep, 
  requestApprovalStep, 
  executionStep 
} from './incident-agent/workflow';

// Plug and play steps directly into your enterprise workflow
export const customEnterpriseWorkflow = createWorkflow({
  id: 'enterprise-ops-pipeline',
  inputSchema: z.object({ errorLog: z.string() }),
  stateSchema: myCustomStateSchema
})
  .then(triageStep)         // Runs grandchild diagnostics & WASM compression
  .then(safetyAuditStep)   // Executes Enkrypt AI safety guardrails
  .then(requestApprovalStep)// Pauses state machine for human confirmation
  .then(executionStep)     // Runs approved command in target shell
  .commit();
```

## 👥 5. Decoupled Parent & Grandchild Agents
You can invoke our agents independently from any chat script, Slack bot, or cron job:

```typescript
import { incidentAgent } from './incident-agent/agent';
import { createGrandchildAgent } from './incident-agent/grandchild';

// Call SRE Incident Commander
const plan = await incidentAgent.generate("System CPU Spike at 99%");

// Spin up a temporary log parser grandchild to analyze metrics
const grandchild = createGrandchildAgent({
  id: 'temp-log-parser',
  name: 'Log Parser',
  instructions: 'Identify core errors',
  tools: { readLog: myCustomReadTool }
});
const diagnostics = await grandchild.generate("Find errors in sys.log");
```
